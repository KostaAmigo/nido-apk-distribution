# NIDO APK Distribution

Public distribution channel for **NIDO** (com.meetflow.app) Android preview/test APKs.

This repository contains **only release assets** (APK files). It does **not** contain the NIDO source code, secrets, or any service data.

## Latest release
See the [Releases](https://github.com/KostaAmigo/nido-apk-distribution/releases) page.

## Install
1. Download the `.apk` from the latest release.
2. Open the file on Android and allow "install from unknown sources".
3. Signed with the NIDO EAS keystore, so it updates the existing app in place.
